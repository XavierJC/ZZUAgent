## 当前授权：重构第一阶段

用户以“开始下一步开发”批准此前提供的第一阶段指令。目标是课程学习空间和可维护模块边界，复用既有服务与业务事实，不扩大正式题库/BKT范围。

| 步骤 | 交付 | 验收与状态 |
| --- | --- | --- |
| 审查与备份 | 实库schema13/45表、源码ZIP、逐表摘要 | 已备份，完整性/外键通过；结束时再比较 |
| 课程空间 | 三学生入口、独立管理、课程上下文与旧链接 | 已实现，浏览器/兼容回归通过 |
| 状态边界 | 按需创建、跨页保留、统一保护草稿、退出停止监听 | 已实现；专项测试覆盖模块请求与学生切换 |
| 页面与API | 路由拆包、按业务归属接口与组合根 | 已实现；旧根级导入/API保留 |
| 资料目录独立 | 只读资料列表/原文、不初始化题库和练习 | 已实现；关联编辑有独立草稿、版本和回执 |
| 综合验证 | 原学习闭环、来源约束、草稿/历史恢复、HTTP/浏览器 | 后端615、前端210、HTTP29组与构建通过；助手浏览器14组 |
| 文档整理 | CURRENT_STATUS、精简规则、长期上下文与历史索引 | 已整理；原件与备份按字节一致 |

交付标准：新空间实际可运行；旧ID路由、问题/笔记/自评/作答草稿、来源选择和不确定回执保持；刷新和页面初始化不分题、不提交、不重发模型；未进入模块不读取其业务数据；正式事实保持；桌面和窄屏可操作。

本轮模型：真实0，HTTP模拟4次。无新增依赖、无数据库迁移，不修改后端业务/解析/检索排序。阶段完成后停止。

## 下一阶段建议（未授权实施）

优先用一份真实教师课件和一份真实习题建立固定验收样本，先核对原文与提取缺失，再选择针对性的解析或检索改进；不以新增测试数量代替真实内容质量检查。

| 阶段建议 | 目标 | 验收 |
| --- | --- | --- |
| 资料学习质量 | 原件、逐页覆盖、公式/表格缺失、检索依据 | 有人工参考的固定样本，报告命中、漏检和无法解析部分 |
| 习题整理质量 | 原题型、条件、子问、选项/答案来源与异常处理 | 完整题普通练习可用，缺项不编造，旧编辑不被覆盖 |
| 个性化衔接 | 正式诊断→资料讲解→练习/正式复测 | 原规则依据可解释，普通练习不冒充BKT证据 |

若引入新的付费服务、改变外发范围、数据库契约或正式测评准入，先提交具体方案并等待确认。

## 当前遗留

- 原5点10道正式演示题与40候选仍待负责人内容审核；正式新题不足未通过本次重构解决。
- 真实课件、复杂公式、扫描和原题识别仍有质量限制；OCR/语义嵌入/检索排序本轮不改。
- 真实教学效果未验证；原55/15评估与失败记录继续保留。
- 后端工作台与仓储的进一步边界整理属于后续评估，当前不全面重写。
- 构建拆包有实际体积记录，但未做弱网或大规模性能基准；不把入口包减少等同全部页面总下载减少。
