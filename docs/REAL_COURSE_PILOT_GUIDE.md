## 负责人内容审核顺序

1. **课程构建 → 知识体系**：打开“模型评估真实课程试点”，检查1章/1概念及原`model_evaluation`只读关联。明确确认并发布知识体系。
2. **课程构建 → 课程资料**：页面下方“试点课件片段与知识概念”已列出5处候选。展开原始页面，与片段/公式逐一对照；填写本机审核说明并勾选已核对，再确认对应片段。每处确认独立，不等于整份教材已审核。
3. 有误时不要确认。上方打开课件和所选解析记录，在新增候选表单读取对应页，修订转录后保存为另一条待审核片段；旧候选不进入检索。已确认片段可显式撤回，旧问答快照保留。
4. **课程构建 → 习题管理**：检查本标识3道草稿。原文未给标准答案，当前answer均为空；负责人独立解答，核对选项/题型后再填写答案并明确确认。仅此后可进入普通练习，仍不更新BKT。
5. **课程审核与发布**：新建课程草稿，选择刚发布的知识体系版本及“已确认片段可检索”的试点课件。试点可只选该教师课件；也可明确选原课程说明。保存、检查并明确发布**工程演示版**。原10题pending，不能把整门课伪装成已审核正式课程。
6. **我的学习**：选择刚发布的版本，明确开始模型评估会话/诊断。答题后按规则建议进入AI伴学；一键讲解优先选择当前发布允许、且正式知识点关联匹配的教师课件，携带只读学情和规则原因，不自动调用模型。

内容确认前，来源列表没有这份教师课件，发布/问答不会使用未审片段。不要直接将脚本验收中的confirmed=true用于现用数据；那些操作仅在隔离副本模拟用户审核。

## 学生闭环及两个练习入口

目标→原正式诊断→真实答题次数/BKT估计/独立自评→确定性建议→教师课件讲解→普通练习或原正式复测→读取更新状态。

- 只有正式题目服务的作答更新BKT；普通练习记录独立反馈，返回`bkt_updated=false`。
- 无答题证据为待诊断；阅读、模型转录、片段确认、课程发布不产生掌握概率。
- 模型评估仍只有原2道正式题。试点HTTP中第一次答错、第二次答对后，若未满足阈值而无新题，真实规则返回题目耗尽，不生成新题或演示假进步。
- 刷新/前进后退/历史只读；显式开始/分题/提交才写入。回答历史不重发模型，普通练习不能伪装成正式复测。
- 答题结果、BKT估计、自评、规则原因及模型解释分开显示。

## 教师RAG与外发

复用现有TF-IDF与来源验证。只有本标识、当前课程、**已确认片段**可检索；不把教师PDF改写进原课程说明，也不复制到个人笔记索引。试点小语料的派生TF-IDF索引在每次所选检索时重建，不存共享缓存，因此重启可恢复，不存在磁盘旧索引继续返回的问题。

来源版本绑定文档元数据revision、文件版本、解析头及确认片段ID/revision/转录内容/知识体系版本。检索前及返回前重验；调用模型前再次重验。原文件指纹/页面片段不符、重解析、文件更新/删除或撤回确认都会让旧来源失效。发布清单绑定同一已确认知识体系版本及片段版本集合，草稿不得把另一个体系版本伪装成当前映射。

可复用同一当前文件版本的原生/视觉解析页，但每条关联还绑定当时的解析头；再次重解析必须重新取页核对。选页视觉转录不会覆盖整份文件的其他页。模型解释字段不自动进入课件原文索引。

AI伴学可仅本地检索；无模型密钥仍可工作。模型模式增加**教师课件独立的逐轮外发说明与勾选**，只发送问题及所选课件实际检索到的已确认片段。个人笔记同意不能授权教师课件，页面识别同意也不能授权聊天；更换问题/来源/模式及发送后清除同意。未同意教师外发时整轮降为本地，模型调用0。

服务端上下文冻结学生/课程、来源ID/版本、学习版本和两个外发标志。模型工具不能增加来源、换学生或改BKT。引用只能来自本轮已取得片段；资料外解释仍按原混合回答规则标为模型知识。当前学习指南可本地使用选中片段，但没有新增教师资料模型外发授权界面，因此教师来源的模型指南会降为本地规则结果，不能复用Chat同意。

## 引用与API

统一来源类型新增`teaching_material`。来源摘要仍兼容旧course_material/personal_note，教师来源可附document_id/version_id/run_id。

引用新增document_id、version_id、page_number、concept_id、architecture_id、architecture_version、excerpt_origin、original_text_snapshot，保留原citation_id/source_id/source_version/chunk_id/raw_md等。校订转录与原生文字分别标识；历史保存当时片段，点击抽屉可查看同一文件版本的原页图。资料软删除后当前检索关闭，历史片段不物理清除，原页图可能不再可用。

新增前缀`/api/v1/students/{student_id}/teaching-material-links`，四个操作/三条路径，现服务86条OpenAPI路径：

| 方法 | 子路径 | 输入/效果 |
| --- | --- | --- |
| GET | 空 | 当前标识关联、页码、候选/确认/撤回状态、当前有效性 |
| POST | 空 | request_id、document_id、run_id、ordinal、architecture_id、concept_id、start_offset/end_offset、可选excerpt_md；只建candidate |
| PUT | `/{id}/review` | request_id、expected_revision、confirmed、architecture_version、reviewer；确认须已发布且已确认概念及当前来源 |
| GET | `/requests/{request_id}` | 只读原操作回执 |

同ID同内容幂等，不同内容409；旧revision409；跨作用域404；非法范围422；请求体最多256KiB。试点每标识最多200条关联，无后台无限提取或付费重试。前端草稿独立本地保存，写前保存请求编号；刷新只查回执，不自动重发。

原`knowledge/sources/search`、Workbench与教学会话接口增量兼容。问答新增可选`allow_teacher_external=false`，原请求无需该字段；默认不会外发。课程发布仍只引用原正式运行题库，教师片段并不获得评分权。
