## 二、项目申报内容

### 1. 项目简介

面向高校《机器学习》课程中学生知识薄弱点难定位、学习与测评反馈脱节的问题，拟开发智学郑大 EduAgent 个性化学习辅助系统。系统以学生学习目标为入口，通过客观题诊断、课程资料检索、知识讲解与针对性练习，持续记录学习过程。采用贝叶斯知识追踪估计知识点掌握概率，结合先修关系规划后续内容，形成诊断、学习、测评与计划更新的闭环。初版限定线性回归与损失函数、梯度下降、逻辑回归、过拟合与正则化、模型评估五个知识点，提供简洁的 Web 学习界面。

### 2. 主要功能与智能体方案

系统提供课程资料问答、学情诊断、个性化建议及客观题组卷评阅，已用 Vue 3 实现学习目标、答题反馈、掌握度、资料和历史页面。后端采用 Python 与 FastAPI，使用 SQLite 保存学习记录，自主实现 BKT；评分和概率更新由确定性程序执行。已用 LangGraph 编排单一 DeepSeek 助教，支持读取学情、检索课程资料和获取合法练习分配，学习推进受先修规则约束。RAG 使用 FAISS 与本地 TF-IDF 基线，回答附实际检索章节，来源不一致或模型失败时明确降级。现用十题演示库，另备四十题待审候选及审阅单，五份课程说明也待审。后续完成内容校验、正式题库切换、误检改进及浏览器人工验收。

### 3. 项目创新点或特色

项目拟将知识追踪与智能体教学规划结合，突出三项应用特色。第一，以答题证据驱动 BKT 状态更新，为学习建议提供可追溯的量化依据。第二，将掌握度、近期错误与先修关系共同纳入行动选择，使系统能够复习薄弱先修知识或推进到后续内容。第三，将测评、状态保存与计划更新连成可执行流程，记录行动依据和课程资料出处，便于复现与检查。创新定位于课程场景中的方法组合和工程应用，不宣称发明 BKT 或已有学习效果提升；已完成有限合成策略比较，后续通过独立场景和条件允许下的自愿试用验证价值。

## 三、项目基础、计划与预期成果

### 1. 当前基础与下一步计划

已实现五知识点、BKT、评分存储、HTTP、LangGraph/DeepSeek 及 Vue 页面。现用十题演示库，另备四十题待审候选。后端 225 项测试通过，此前前端 18 项及两条 HTTP 复验通过，两组真实模型场景完成工具和引用。依据不足时不调用模型；两个自建检索开发集共五十五条，仍有课程外误检。新增八个同学情的合成策略比较，同时展示先修推进约束和题量不足暂停。下一步内容审阅、正式题库切换、独立评估及浏览器验收。无真人试用或学习效果证据。

### 2. 预期成果与效果验证

预计形成覆盖五个知识点、含 30～50 道人工校验客观题的课程学习原型，支持有出处的问答、答题诊断、学习状态展示及动态建议，并提供运行说明与演示材料。验证分三层：使用固定数值和异常场景检查算法、评分及存储；重放相同合成答题历史，在同一状态比较固定题额与自适应策略的下一步行动、先修约束和停止情况，不假定分叉后的学生表现；有条件时邀请少量自愿用户试用，记录样本量、交互问题与反馈。现有测试只证明工程行为，尚无真实学生成绩或学习效果提升数据，最终如实报告结果与局限。

### 3. 数据使用情况

按当前开发与验证方式，建议勾选“仅使用公开数据或自建数据”和“使用模拟或脱敏数据”。当前具体使用自建题目、课程说明、知识点配置与合成答题记录，不接入学校内部系统，不采集真实学生身份信息。后续外部课程资料需核对来源与使用许可；如试用涉及个人信息，应重新确认告知、授权及数据使用选项。
