# 入口整理与Agent原题提取（2026-10-22）

本轮按用户“开始开发”授权完成五批次工程实施。FastAPI/Vue/SQLite/LangGraph保持，新增依赖0；版本清单仍0.4.1，不宣称完整v0.5.0发布。实际结果见[验收记录](EXTRACTION_V2_VALIDATION.md)。

## 从哪里开始

主导航依次为学习概览、AI助教、课程资料、我的题库、我的笔记。

- 学习概览：正式目标、原练习/掌握状态、只读主客观对照和规则重点、正式历史入口。
- AI助教：原三栏来源/对话/Studio，保留原引用和逐轮个人外发授权；题库、上传与知识体系编辑器已移到独立入口。
- 课程资料：资料目录与上传、知识体系、原有课程片段检索。目录仍投影原存储，不重复复制笔记/课件；教师课件仍未全面接入RAG。
- 我的题库：提取任务、待审核题、原文/修正稿对照、普通练习及历史。
- 我的笔记：原Markdown编辑、草稿和版本恢复。

采用轻量hash导航，例如 `/#/materials?resource=<资源ID>`、`/#/bank?question=<题目ID>&view=bank`、`/#/notes?note=<笔记ID>`；不新增路由依赖。资源可打开相关题目，题目可返回原资源。浏览器前进/后退、刷新恢复地址及本机草稿，演示标识仍由原存储恢复。请求编号与哈希收进技术详情。

## 识别、校对和练习

1. 在课程资料选择已有文件/笔记，或粘贴原题。文件可复用已保存本地/视觉解析，无需重复上传；重新选择解析记录不会调用模型。
2. 选择“Agent语义提取”，限定最多3个相邻单位、18000字符。PDF/图片建议同时使用原页图；选择原页图会发送该选定页的图片和解析文本，不会发送整个文件库。
3. 阅读外发说明，明确同意本轮发送所选原文/页图至DeepSeek，再开始。选择来源本身不是授权；修改选页/解析/文本会清除同意，提交后同意也清除。
4. 到我的题库查看提取任务。刷新和轮询仅GET，不重发模型。完成后逐题校对原图、原文、题干、选项、子问、公式和缺项；没有来源答案时保持未知。
5. 明确人工核对后进入普通练习。客观答案另行确认；保存草稿不代表已审阅。
6. 简答/计算/证明/填空/多选本轮使用文字作答，可保存草稿、刷新恢复和提交；不自动判分。“需复习”是个人主观标记，不进入客观错题或BKT。

没有模型密钥时，选择“本地规则 · 不外发”或手工录入。规则是保守降级，仍可能需要较多校对，不能与语义提取质量等同。

## 修正旧题

迁移没有重新分类或改写现有12道个人题。打开旧题，保存本机修改后，可“局部重识别”：本轮重新同意发送原题关联的来源页；任务绑定原题revision，源文件或原题变化时禁止过期发布。

模型修正始终先生成**独立草稿**。打开修正稿时左右对照原题与修正内容；可保留原稿并返回，或显式接受为原题的新草稿revision。接受须原题/修正稿/来源同时有效，随后重新人工审核；旧版本及已作答快照保持。若原页包含多道题，应选择对应修正稿或分别审核新草稿，不能把整批自动覆盖到一道原题。

## 题型和答案契约

题型为 `single_choice / multiple_choice / true_false / fill_blank / short_answer / calculation / proof / unknown`；旧 `other`仍能恢复，不被自动改写。题型与评分能力分开：只有单选/判断且人工确认答案，才按冻结快照确定性评分。

题目JSON保留原字段，按需增加：

| 字段 | 含义 |
| --- | --- |
| shared_context | 共有材料、父题条件 |
| subquestions | 最多20个一层子问，使用同样题目结构 |
| answer | 单选/判断原文或人工答案键；未知为null |
| answer_keys | 多选答案键，暂不自动评分 |
| answer_text | 原文或人工参考答案文字，公式原样保留 |
| dependencies / issues | 图表依赖、缺项、无法辨认及待核对项 |

原文提供、模型提取未核验、人工确认及未知答案分开显示。模型提取的答案即使有原文支持，也保守标为模型来源待核验；识别不求解。修改答案/解析取消沿用确认，已开始练习的评分依据不随题目编辑改变。

## 服务端提取流程

```text
POST登记任务及请求摘要（事务）
→ 单一队列领取
→ 选定原文/受限原页渲染
→ LangGraph：语义提取→程序校验→必要时一次结构复核
→ 再核验学生/课程/资料版本/解析/原题revision
→ 一次事务发布新草稿与任务结果
```

原文是选定的完整相邻单位，不使用零散RAG召回来还原习题。模型没有SQL/文件/正式评分/推进/BKT工具。身份、资料、版本、页码、调用上限在服务端锁定；模型仅返回结构化候选。

- 独立预算：每次最多10000输出token，每任务最多2次（含一次格式/来源复核），每批最多20道主问题。输出截断明确失败，缩小范围后需用户新建任务；不自动续写。
- 原页图复用已有受限渲染进程，最多3页，保留位置。文本模式检查本题原文引句、选项/答案来源、题干词面支持及结构；这些检查不是完整语义正确性证明。
- 判断题固定“正确/错误”控件不冒充原文选项；兼容无歧义的判断文字与多选答案表示，仍核验本题原文，不借用同页另一题答案。
- 图片转录明确 `image_transcription_unverified`；图像内容无法通过文本匹配证明完整正确，必须校对原图。
- 网络调用与渲染不持有SQLite写事务。调用前记录意图；保存前再次校验。超时/网络不确定/重启中断置uncertain，不自动重发。版本竞争置stale，不发布旧草稿。
- 一标识同时最多1个运行任务，保留最多200个任务、1000题（含归档）。单worker，本机资料目录锁沿用旧机制。

## API增量

前缀 `/api/v1/students/{student_id}`，本机演示作用域不是身份认证。

| 方法与子路径 | 用途 |
| --- | --- |
| GET personal-bank/extraction-capabilities | 服务、独立预算、范围限制 |
| POST personal-bank/extraction-tasks | 202登记异步语义提取；相同ID/内容返回原任务，不重复调用 |
| GET personal-bank/extraction-tasks | 最近50个任务 |
| GET personal-bank/extraction-tasks/{request_id} | 恢复状态/新草稿ID/调用次数/错误；不执行模型 |
| PUT personal-bank/practice/{session_id}/draft | 保存文字作答和主观复习标记，独立revision和request_id |
| POST personal-bank/questions/{id}/accept-proposal | 显式接受修正稿，校验双方revision和来源 |

任务请求沿用原提取 `resource_id + source_version + run_id + ordinals` 或 `text` 二选一，另需 `request_id / consent=true / include_images`；重识别增加 `target_question_id / target_revision`。选择空页集不扩大范围；跨学生资料拒绝。请求体上限仍256KiB。原 `POST personal-bank/extractions`维持本地同步，不暗中改变为付费调用；原CRUD/实践接口兼容，文字提交使用原selected_answer字段（扩到16000字符），不支持的题型不客观评分。

草稿请求：`request_id, expected_revision`（首次0）, `response_text, needs_review`。接受修正：`request_id, expected_revision, proposal_id, proposal_revision`。相同请求ID不同内容409，旧revision409；未知资料/题目/任务404，不泄露其他演示标识的内容。

## SQLite迁移与回退

真实schema9/34表 → **schema10/36表**。只新增 `question_extraction_tasks`（原文/来源/目标版本、请求hash、状态、结果、调用计数）及 `personal_practice_drafts`；原题、修订、练习、正式学习表不改列、不改旧行。可扩展题型保存在既有JSON，不批量重写旧JSON。

先在副本演练，再停旧服务并做SQLite备份、摘要核对、事务DDL、完整性和外键检查，已验证原34表逐表摘要一致，旧schema9代码接受恢复9副本且拒绝10。

- 开发前代码/数据库：`data/local/extraction-v2-prechange-08c1caa3/`（不含.env）。
- 现库迁移备份：`data/local/eduagent.before-v9-490cbc4ba29b.sqlite3`。
- 回退审计目录：`data/local/extraction-v2-rollback-97d2d2fb/`，同时保留恢复9副本、升级10副本及旧代码。
- 详细摘要/校验：[迁移报告](../data/evaluation/extraction-v2-migration-v1.json)，[只读部署报告](../data/evaluation/extraction-v2-deployment-v1.json)。

需要回退时先停服务，并对**届时**schema10库再次备份，保留新增任务/文字草稿；使用旧代码与恢复9的独立库路径/端口、保留的原件版本，不能以9副本覆盖升级库。旧服务不可直连10库，不能只修改user_version伪装回退。升级后新增数据不会自动回灌旧版本，需另行审查导出。原件版本/历史快照仍保留，软删除/归档不是物理清除。

任务上下文和题目证据保留所选原文快照，用于故障与历史回溯；删除笔记/课件使当前来源失效，不物理清除既有题目和任务快照，也不自动重新发送模型。当前没有新增彻底擦除功能。

## 当前限制与停止范围

固定自建样本和清晰图片PDF不代表真实试卷的识别准确率；未完成人工题目审阅、独立扫描资料评估和教学效果验证。模型仍可能漏题/错分/转录公式；程序词面校验不是OCR或数学等价验证。每批限3相邻页，不实现全文件自动分批循环；大文件由用户选段，避免无界收费。

真实浏览器桌面/窄屏/键盘验收未执行；此前localhost浏览器访问被拒，未换工具绕过。CSS与jsdom工程测试不替代人工。主JS约712kB，仍有默认500kB提示。40道正式候选题仍待人工确认，原55检索案例和5/15课程外误检保持。教师课件RAG全面扩展、4B-3映射、新题生成、主观自动评分、正式BKT准入均未实施。
