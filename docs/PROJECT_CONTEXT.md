# EduAgent 项目上下文

更新日期：2026-10-26（Asia/Shanghai）。[当前状态](CURRENT_STATUS.md) · [开发计划](DEVELOPMENT_PLAN.md) · [历史原件与报告](history/README.md)。

## 项目目标

智学郑大 EduAgent：基于知识追踪与智能体驱动的个性化学习辅助系统。面向高校《机器学习》课程，由一人开发，用于郑州大学首届AI智能体创新应用大赛A2“AI助教·教、学、评闭环与个性化学习”。

核心链路：学习目标 → 正式诊断 → 学情分析 → 来源可追溯讲解 → 普通练习或正式复测 → 正式评分更新BKT → 重新规划。

申报及演示时间以官方最新通知和学院安排为准。已核对的官方附件位于 `docs/references/`；原赛事核对记录保留于[重构前上下文](history/pre-refactor-stage1/PROJECT_CONTEXT.md)。不把历史核对日期当作新通知验证。

## 产品结构

学生默认进入持久化学习笔记本，按主题组织资料、问答、普通练习和笔记。主导航为学习、练习、进度；练习内区分自由练习和测一下。记录与资料/高级设置收起，旧正式诊断路由和管理能力保留。

2026-10-25用户明确要求设计人性化、尽量交给AI处理并减少复杂流程。正常路径提供合理默认值，名称/学习范围可选；成功上传后完成当前主题关联，现有题目整理后直接练习。仅在缺项、失败或真正外发时提示必要选择，不把课程构建和发布作为正常阅读/诊断前置。复用现有AI能力，不由此扩大外发、付费或正式评分授权。

失败资料同样提供删除动作，不能因不可参与问答而剥夺管理入口。主题资料窗口的上传资料删除复用既有软删除接口，不物理清除原件和历史；课程内置资料与个人笔记不误用该接口。用户本轮要求删除不等于批准此前PDF编码修复或自动重试全部失败资料。

前端采用统一的浅色语义Token与共享导航；手机入口不能通过隐藏辅助导航丢失功能。首页诊断覆盖和练习范围计数必须来自保存事实，并明确各自含义。Notebook可选task路由只恢复视图，不能因此自动作答、分题或重放模型；低频审核记录按需展开。

资料学习以问答为主区，原文/引用/笔记按需查看。已保存可读上传可直接受控问答，不以课程知识体系或发布作为阅读前置。发布课程的正式教学链路保持原版本约束。

## 当前技术架构

- 前端Vue3/Vite：app负责布局、兼容hash路由与作用域；features分别管理notebooks/materials/chat/practice/notes/learning/authoring；shared提供请求和基础能力。复用现有Markdown/LaTeX渲染及组件。
- 状态模块首次使用时创建，和页面组件生命周期分开。页面按路由拆包；状态跨页面保留，退出应用停止监听，学生切换重置。
- 后端Python/FastAPI：API、领域算法、服务、仓储、解析、检索和模型适配分层。LangGraph保持单一Agent与明确工具预算。
- SQLite保存学习事实、笔记、资料元数据、知识体系、发布和请求回执；当前实际版本见CURRENT_STATUS，不从旧文档推断。
- Notebook只保存显式关联和独立版本，不复制原件；NotebookContext固定学生、课程、笔记本与来源版本，组合原Workbench/普通练习能力。执行前预留问答请求，未确认执行只查询记录。草稿、会话和普通练习回执按Notebook作用域隔离。
- 原始文件与Markdown独立于解析文本、知识结构和可重建索引。检索复用本地TF-IDF/FAISS词项基线，未升级为语义嵌入或图检索。
- DeepSeek用于受控问答、可选指南及显式选页/习题处理；本轮重构不实际调用模型。无密钥时本地解析和检索仍应工作。

本机演示作用域不等同真实身份认证。不引入大型向量库、图数据库、多智能体或完整教师平台。

## 学习状态与评分

正式BKT范围：线性回归与损失函数、梯度下降、逻辑回归、过拟合与正则化、模型评估。2026-10-25用户另行授权现有题目正式准入，最新数量见CURRENT_STATUS。共享40题包含原10题，个人准入按学习标识隔离；AI检查与人工确认分别记录。缺少答案、缺条件、争议或范围外题不强行作为客观证据。

正式准入保存在本机metadata内，冻结题目、答案与来源版本并绑定配置摘要，不改原文件及历史事实。原发布快照保持，仅允许已验证的追加兼容；个人题的所有者、revision、原件版本、删除和就绪状态由服务端校验。旧程序配置不兼容时必须拒绝连接。扩题及读取不更新BKT，用户明确正式提交后才按原公式更新一次。

BKT依据服务端正式答题事实按公式更新；先验是模型假设，没有答题证据时显示“待诊断”。参数未经真实学生数据标定，不宣称模型估计等于真实能力。

独立四级自评与可空1～5信心追加保存，不转换成BKT概率。程序用一致学情快照决定重点和原因；模型只解释既定重点，不修改排序、事实或先修规则。

普通练习独立保存；未核验答案仅供对照，correct/score为空。主观文字作答可保存，不自动评分。正式题耗尽后可复习旧反馈，但不制造新BKT证据。

## 资料、原题及来源

支持PDF/PPTX/MD/TXT本地解析，以及现有图片原件管道；扫描、图像和复杂公式可能无法可靠提取。选页视觉识别是可选外发流程，不自动发送整个文件。

2026-10-26用户授权PDF局部容错：保留可解析正文和物理页码，局部失败页保存为空并标缺失，不得让它进入检索；不可恢复字符可见标记，不能冒充完整公式。有效代理字符兼容处理不等于人工核验。文件级/资源限制及其他格式严格编码保持，不因修复而自动重试全部失败或已删除资料。

原题整理遵循原文/原页 → 语义结构化 → 程序检查 → 必要局部复核 → 普通练习或待处理。提取、生成新题、补解答案与正式测评准入是不同任务，不能相互冒充。

来源至少区分课程资料、未核验上传、已确认教师片段、个人笔记。知识章节/概念用稳定ID，正式学习关联只读；同名不自动合并，候选先修不覆盖正式图。

## 受控Agent

学生/课程/请求ID、来源及版本、学情版本、外发许可由服务端绑定。检索和问题改写不能扩大来源范围。空选择不查全库，笔记与文档中的指令均不作为系统授权。

先检索所选资料，再允许模型综合自身知识解释；资料依据与模型补充明确区分，引用只能来自本轮实际取得的片段。

Chat、学习指南、视觉识别分别逐轮授权。未经同意不发送个人/教师片段；不自动发送完整笔记库或聊天历史。不确定执行只查询原回执，不重复付费。

## 数据和验证原则

不虚构模型效果、学生试用、已完成功能或人工核验。自动化验证工程行为，内容审核和真实教学效果分别验收。原55条课程检索评估、15条课程外挑战及误检保持。

备份、数据摘要、完整性、外键及保留新数据的回退贯穿变更。密钥不入源码、报告或日志。来源使用在用户授权范围内，不公开分享教师课件。
