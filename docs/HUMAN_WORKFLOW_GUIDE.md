# 简化学习流程使用指南

2026-10-25。本轮按用户“设计要人性化，能交给AI就交给AI，使用流畅简单”的要求实施。实际验证见[报告](HUMAN_WORKFLOW_REPORT.md)，唯一当前状态见[CURRENT_STATUS](CURRENT_STATUS.md)。

## 开始学习

打开[学习空间](http://127.0.0.1:8000/#/notebooks)，点击“开始学习”即可。昵称自动生成，具体学习范围和昵称放在可选设置内；也可恢复已有学习标识。新建主题时名称可以不填，直接使用“新的学习主题”。原学习标识、资料和历史无需重新导入。

主导航只有“学习、练习、进度”。历史和笔记在“我的记录”，资料维护、知识体系与发布等低频功能在“资料与高级设置”。手机通过左上角菜单访问相同入口，旧hash链接继续可用。

## 添加资料并提问

进入主题，点击“添加资料，开始学习”或资料栏的加号。已有资料点击“加入主题”立即完成关联；上传成功且解析就绪的资料自动关联，无需再保存一次资料范围。新增的非私人笔记资料会勾选参与问答，已有未选资料保持原状。个人笔记仍需要主动勾选。批量移除和换版操作放在可选管理模式。

上传失败或无可读正文时保留原件并提示原因，不把空内容加入问答。可使用现有选页识别入口；没有自动调用模型补救失败文件。

2026-10-25补齐：已有上传资料（含解析失败）右侧可点击“删除”，在本行确认后从资料库移除，所有主题停止使用，历史和原文件保留。批量模式已选择的失效关联允许取消选择。[使用与验收](SOURCE_DELETE_REPORT.md)。

输入问题后发送。模型不可用时明确使用本地查找，有出处的片段仍可阅读；启用现有模型时沿用受控RAG解释。私人资料外发仍在实际发送前清楚显示范围并取得本轮同意；选中资料不等于同意外发。

## 练习和测一下

“练习”内有两个清楚的选项：自由练习用于巩固，“测一下”根据正式答题更新掌握度。

导入习题支持上传或粘贴。现有AI服务可用时，复用受控识别流程；当前请求的文件权利与发送同意合并呈现，不需要重复勾选。识别设置和页范围默认收起，默认最多前3页，不能据此发送整份文件。模型禁用时自动使用本地整理。完成后点“开始练习”直接进入本批可练题目，缺项题单独提示。

“测一下”在用户明确点击开始后完成原课程绑定和第一题分配，普通使用无需先进入课程管理或发布。页面挂载、读取和刷新不会自动分题。提交后显示反馈，继续下一步仍需明确点击。

当前正式题范围沿用此前准入结果，见[题目准入指南](FORMAL_ADMISSION_GUIDE.md)。本轮简化界面没有自动批准所有以后上传的题，也没有补造缺失答案或引入主观自动评分。普通练习、资料问答与自评均不更新BKT。

## 运行与回退

运行方式、Python和前端依赖不变，无新增依赖。在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn eduagent.api.app:create_app --factory --host 127.0.0.1 --port 8000
```

修改前端后在`frontend`目录运行`npm.cmd run build`。本轮仅改前端和文档/验证脚本，无数据库迁移。源码和现用库备份在`data/local/human-workflow-20261025-211109/`；回退界面应从源码备份恢复本轮前端文件再构建，不需要覆盖数据库。若以后数据已有新增，仍必须保留，不能用旧库覆盖。

只读界面刷新保留同一诊断题的当前选择；这不等于承诺关闭浏览器后恢复未提交正式答案。更新构建期间已打开的旧页面遇到旧资源失效时，需要刷新一次。
