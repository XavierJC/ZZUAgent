# 失败资料删除入口修复

2026-10-25。用户指出解析失败资料在选择窗口中无法删除。本轮直接补齐前端入口，并通过现有本机接口删除用户指明的“机器学习-第7讲-决策树1”。此前PDF数学字符兼容修复仍未实施，本轮没有改后端解析代码。

## 原因与修改

后端早已有带学习标识、版本校验和幂等编号的软删除接口；资料选择窗口只暴露选择/加入，失败资料被禁用后没有删除动作。

- 新增`frontend/src/features/notebooks/NotebookSourceRow.vue`，上传资料无论是否解析成功均显示删除按钮。点击后在本行确认一次，可取消；确认说明所有主题停止使用该资料、历史记录保留。课程内置资料、笔记和题目不误用上传文件删除接口。
- `NotebookPage.vue`调用既有资料模块删除，并刷新目录和当前主题，不自动提问、分题或重新解析。批量模式已勾选的失效资料允许取消，避免无法从主题移除。
- `features/materials/useCourseDocuments.js`新增按ID删除，复用原请求编号持久化和版本校验。保留其他已打开资料及上传草稿；学生切换期间的旧响应不能触发新作用域操作。回执未知时只查询，不自动再次DELETE。
- `shared/human-workflow.css`增加资料行按钮/确认的手机布局。原`remove()`调用兼容保留。三个测试文件补充上述行为。

正常流程：学习主题→资料加号→目标上传资料右侧“删除”→本行确认。刷新浏览器一次即可载入新版。删除不再要求资料先解析成功，也无需进入课程构建或发布页面。

现用操作通过原DELETE API完成，没有直接SQL改状态，没有物理清除原文件或历史解析。删除操作前备份位于`data/local/source-delete-20261025-222024/`，含现用库、源码ZIP、逐表和文件指纹。回退前端不回写旧数据库；如需要恢复已删除资料，保留原件和后续新增数据后按具体方案处理，当前界面没有承诺回收站恢复。
