# 正式诊断题准入

2026-10-25 用户明确要求将现有题目用于正式诊断、更新掌握度。本轮授权包括既有题的准入与必要后端兼容，不包括新知识点、生成新题、主观自动评分、外发资料或真实收费调用。

## 方案

不迁移表结构。原10题和候选40题文件不改；在本机SQLite metadata内保存不可变AI检查记录、共享40题以及按学习标识隔离的个人题快照。候选40题包含原10题，新增30题。个人题仅纳入原有明确答案、完整且属于原五知识点的判断题，显示AI检查，不冒充人工审核。缺答案、缺条件、SVM/决策树等超范围题、存在争议的答案本轮不准入。

启动时按原库配置、准入记录内容摘要校验，旧代码因配置不匹配拒绝连接，不能静默接入新题。原评分公式、BKT参数、先修和20轮上限不变；准入不修改学生revision或掌握度，不把过去普通练习补算为正式证据。

现有待答分配保持原题、答案版本和题库版本；已发布课程保留原快照，只允许经过核验的追加兼容。新分配记录本次题库版本，个人题评分再次核对所有者、题目revision、来源版本、删除与就绪状态。页面读取不分配、不提交。原题耗尽的未评分终止分配可在用户明确点击继续后恢复，原终止快照保留在metadata。

## 应用与回退

`scripts/admit_formal_questions.py --db <本机库> --plan <data/local内的AI检查计划>`只预览；应用需显式`--apply --backup <不存在的备份路径>`。先对副本回归，再停写现有服务并备份，在事务中仅增加准入metadata并更新配置。完整性、外键、原表摘要和原件指纹须核验。

回退必须先保留届时数据库与全部新增作答。在独立路径恢复旧代码及准入前备份供旧历史查询，升级后库保留原样；不能用旧库覆盖后来数据，不能删除准入记录让旧代码接管已经出现新题作答的库。本轮不提供新旧评分事实自动合并。

实际数量、测试结果与运行版本只维护于CURRENT_STATUS；过程、失败和限制见FORMAL_ADMISSION_REPORT。
