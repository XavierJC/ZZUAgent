# 现有题目正式诊断准入报告

日期：2026-10-25（Asia/Shanghai）。[当前状态](CURRENT_STATUS.md) · [使用及回退](FORMAL_ADMISSION_GUIDE.md)。

## 结果

用户在讨论AI检查与题目数量后明确要求将现有题目用于正式诊断、更新掌握度。本轮已实施并部署到本机8000服务。

共享课程题由10道增至40道，包含原10道、实际新增30道，每个原知识点8道。个人27道中3道判断题纳入其原学习标识，原题目、原状态及普通练习记录不被改写；该标识可用43题，其他标识共享40题。没有把两个标识的私人题合并共享。

其余24道保留：22道没有参考答案（其中也含条件缺失、错分题型、SVM/决策树等范围外内容），另有1道带答案的SVM题不属于原五点，1道“K越大交叉验证方差必然越小”判断题表述有争议。该题原已确认的普通练习记录仍保持，没有因本次AI检查重算或删除。未补解缺失答案、生成新题、扩充BKT知识点或实现主观评分。

本轮AI检查为助手核对现有文本、公式及保留转录，并复用21个独立数值检查；没有运行新付费模型，也没有逐页核准原PDF。准入记录标记AI检查，人工内容核验和真实教学效果仍未验证。

## 实现

- `backend/src/eduagent/services/formal_admission.py`：在既有metadata中读取不可变准入记录；核对原配置和原题不被修改；构建共享及按标识隔离的题库。个人题再校验所有者、题目revision、题目/来源摘要、原件版本、软删除、解析就绪及重解析状态。
- `services/learning.py`：新分配使用准入范围，评分继续使用原确定性选项判分和BKT公式。旧待答保留原题库版本，新作答保存新版本。用户显式继续时才恢复原题耗尽的未评分终止分配，原终止快照保存在metadata；刷新不分题或重交。
- `services/guidance.py`：剩余题数统计整个题库，修复原先只计算默认返回一题的问题；个人题纳入本标识的剩余题数。
- `services/course_releases.py`、`services/teaching.py`：原发布快照不改，只允许已核对的追加兼容；实际正式作答继续保存题目与课程来源快照。页面获得实际题量与AI检查说明。
- `api/app.py`、`api/schemas.py`：健康接口在存在准入时显示共享题40/AI检查40；未准入库保留原响应形状。公开待答仍没有答案和解析。
- `frontend/src/features/learning/useWorkspace.js`、`frontend/src/views/LearningOverview.vue`：显示当前课程/个人诊断范围与AI检查状态，明确正式提交才更新掌握度。
- `scripts/admit_formal_questions.py`：带内容摘要的本机计划预览、备份与事务应用；重复覆盖或检查后变化会拒绝。具体个人题ID、来源和计划只保留在忽略的data/local目录。
- `scripts/verify_formal_admission.py`、`backend/tests/test_formal_admission.py`：隔离真实HTTP及评分、版本、作用域、故障回滚和旧配置拒绝验证。
- CURRENT_STATUS、PROJECT_CONTEXT、DEVELOPMENT_PLAN、README、AGENTS及本指南/报告更新本次明确授权和实际边界，不覆盖历史原件。

## 数据保护与回退

现用schema14、50表不变。部署仅新增准入metadata并更新配置绑定；原49张业务表摘要、29条正式作答和180个既有资料/知识/题库/评估文件指纹一致。原10题与候选40题的文件保持原样，准入的AI检查状态独立保存，不冒充文件内人工审阅记录。

旧代码的配置绑定因缺少新准入摘要而拒绝升级库，未通过修改schema版本绕过。回退演练从准入前备份恢复独立旧库，旧29条作答可读；升级后的隔离库及其新增5条正式作答保留，两份库不互相覆盖。后来浏览器验收又在隔离库新增1条合成作答，没有向现用库新增学生或作答。

备份：`data/local/formal-admission-20261025-203458/`，含源码ZIP、准入前库、应用前即时备份、50表摘要、AI检查计划、隔离库/原件副本与独立回退库。回退操作必须先保留届时新数据，不能直接用旧库覆盖升级库；详见指南。

## 使用与限制

打开[正式学习与复习](http://127.0.0.1:8000/#/learn)，恢复原学习标识，在明确开始诊断/正式复测后作答。题量显示课程与本标识个人范围，页面刷新不会增加证据。普通练习保持独立，不追认历史作答为正式评分。

启动命令与新环境安装仍见README，无新增依赖；仍使用原单Agent和本机服务。后续上传不会因本轮授权无条件自动成为正式题。个人准入题在编辑、归档、原件换版/删除或解析失效后停止分配；已提交反馈保持冻结，未提交的过期版本不能按新内容评分。20轮上限与达到演示阈值后结束仍保留，不保证每个学生逐题做完所有题。

本轮完成后停止，不自动开展其他解析、检索、新题生成、主观评分、新知识点或付费模型阶段。
