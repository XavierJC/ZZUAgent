# 同一学情下的下一步决策对比

记录日期：2026-10-20，运行版本 0.4.1。已完成 8 个合成状态的配对工程比较，结果保存在 [完整 JSON](evaluation/policy-paired-v1.json)。这是确定性教学推进规则的行为验证，不是模型规划能力评测、真人实验或学习效果证明。

## 对比设置

使用当前实际启用的 10 道待审题目；学习目标限定为逻辑回归，包含线性回归、梯度下降两项先修。候选 40 题没有启用。两种策略采用相同的先修顺序、题库顺序、不重复选题规则和累计 20 题上限：

| 策略 | 推进规则 | 结束含义 |
| --- | --- | --- |
| 当前策略 `rules-v1` | 有答题证据、BKT ≥ 0.80 且最近答对才视为达到演示阈值；最近答错先复习；未达阈值而新题耗尽则暂停 | 目标及先修满足模型条件，不代表真实能力已证实 |
| 固定题额 `fixed-quota-v1` | 按先修顺序每知识点固定两道题；不根据概率或正误改变题额和推进；不能凑齐题额时也暂停 | 固定练习额度完成，不作掌握判断 |

固定题额基线仅位于 [离线评估模块](../backend/src/eduagent/evaluation/fixed.py)，不会成为网页中的另一种教学模式。它代表一种明确的固定课程安排，不能代表所有非自适应教学方法。

每条合成历史先通过原有 `LearningService`、确定性评分、BKT 和独立的内存 SQLite 数据库重放；题目必须符合当时实际分配，不能直接写入期望概率或虚构答题。重放后的同一份目标、状态版本、掌握度及已答题集合再交给两种策略，比较一次下一步决定。报告保留每次评分、更新前后概率、两种决策依据和输入指纹，并检查输入未被策略改写。

未生成两条分叉学习轨迹，也未假设某位学生在另一策略下仍会对不同题目给出相同答案。场景共享若干历史前缀，因此 8 个状态不是 8 位独立学生。

## 实际结果

表内概率为相应知识点的 BKT 转移后估计，参数为 `initial=0.20, learn=0.10, slip=0.10, guess=0.25`。阈值和先修图均为待审的演示配置。

| 情景 | 主要状态 | 当前策略 | 固定题额 | 差异 |
| --- | --- | --- | --- | --- |
| initial | 无答题证据，先验 0.20 | diagnose / lr_01 | diagnose / lr_01 | 相同 |
| lr-wrong | 线性回归首错，约 0.1290 | review / lr_02 | practice / lr_02 | 仅行动标签，题目相同 |
| lr-mixed | 线性回归先错后对，约 0.4130 | stopped / 新题耗尽 | advance / gd_01 | 暂停与推进不同 |
| lr-two-wrong | 线性回归两错，约 0.1174 | stopped / 新题耗尽 | advance / gd_01 | 暂停与推进不同 |
| lr-mastered | 线性回归两对，0.82 | advance / gd_01 | advance / gd_01 | 相同 |
| gd-wrong | 线性回归 0.82，梯度下降首错约 0.1290 | review / gd_02 | practice / gd_02 | 仅行动标签，题目相同 |
| gd-mixed | 梯度下降先错后对，约 0.4130 | stopped / 新题耗尽 | advance / log_01 | 暂停与推进不同 |
| goal-done | 三项各两对、各 0.82 | finish / 达模型条件 | finish / 题额完成 | 行动相同，结束含义不同 |

三例改变了题目分配或是否继续，两例只改变行动标签，其余三例行动与题目相同。这里“行动相同”仅比较 action、目标、题号及停止原因，不表示两种策略的解释或结束含义一致。

| 8 次配对查询的计数 | 当前策略 | 固定题额 |
| --- | --- | --- |
| 提供练习 | 4 | 7 |
| 暂停 | 3 | 0 |
| 结束 | 1 | 1 |
| 提供练习时，存在未满足参考条件的先修 | 0 / 4 次练习分配 | 3 / 7 次练习分配 |

最后一行的参考条件是当前程序的“有证据、概率 ≥ 0.80、最近答对”，检查所有间接先修。固定题额本来就不使用该条件，因此差异符合策略定义；不能据此声称其教学错误或当前策略总体更优。当前策略避免了这三次推进，同时出现三次题量不足暂停，这是必须一同展示的代价。

`review` 目前给出复习安排与原因，本次比较没有验证学生是否阅读讲解、讲解质量或额外学习收益。固定题额的 finish 也不应按“达到掌握阈值”计入成功率。这里不报告准确率、显著性、效率提升或学习成绩提升。
