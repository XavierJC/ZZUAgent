## 运行

项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn eduagent.api.app:create_app --factory --host 127.0.0.1 --port 8000
```

打开 [学习笔记本](http://127.0.0.1:8000/#/notebooks)。恢复原学习标识，再从“添加或管理资料”选择已有内容，无需重复导入。终端服务需持续运行，旧不兼容程序不能连接schema14库。详见[README](../README.md)和[使用指南](NOTEBOOK_REBUILD_GUIDE.md)。

下一阶段仅为建议：用真实资料评估解析覆盖和检索质量，逐项改进。须另行确认，不自动实施。
