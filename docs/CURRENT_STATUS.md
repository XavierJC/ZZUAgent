## 运行

项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m uvicorn eduagent.api.app:create_app --factory --host 127.0.0.1 --port 8000
```

打开 [课程学习空间](http://127.0.0.1:8000/#/study)。终端服务需持续运行；前端修改后执行 `npm.cmd run build`。详细说明见[README](../README.md)与[重构指南](REFACTOR_STAGE1_GUIDE.md)。

下一阶段仅为建议：用真实资料评估解析覆盖和检索质量，逐项改进。须另行确认，不自动实施。
