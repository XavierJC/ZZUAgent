# 课程检索开发集基线

实际运行日期：2026-10-20。本轮只评估本地检索，不调用大模型，不评价模型讲解或真实学习效果。

后续同日已实现 `tfidf-phrase-v2` 与助教依据检查，最新测试为后端 202 项、前端 18 项。下方原基线保留不改，新对比见文末。

## 数据与设置

- 资料：5 份自建课程说明、15 个章节，均待人工审阅。
- 问题：[retrieval-dev-v1.json](../data/evaluation/retrieval-dev-v1.json)，25 个课程问题与 5 个课程外问题，预期章节均实际存在。标签待人工审阅。
- 作者可见资料；其中含概念表述、计算解释、中文改述与课程外提问。这是开发集，尚未建立独立的人写测试集。
- 基线：沿用 FAISS 与归一化 TF-IDF，最小余弦分数 0.12，返回最多 3 条。没有根据本次结果调阈值、修改资料、删除失败题或改预期标签。
- 原始逐条结果：[retrieval-baseline-v1.json](evaluation/retrieval-baseline-v1.json)，附数据集与资料内容指纹，包含全部失败和排名。

## 实际结果

| 指标 | 数值 | 口径 |
| --- | ---: | --- |
| Hit@1 | 24/25 = 96% | 课程问题首条结果是否为任一预期章节 |
| Hit@3 | 25/25 = 100% | 课程问题前三条是否包含任一预期章节 |
| MRR@3 | 0.98 | 首个预期章节名次倒数的均值；未命中按 0 计 |
| 课程外问题返回空结果 | 4/5 = 80% | 无相关资料的问题是否确实返回空列表 |
| 新增模型请求 | 0 | 不读取 API 密钥或发模型请求 |

分母分别为 25 个课程问题和 5 个课程外问题，不将两组混为“准确率”。多标签情况下 Hit 只检查命中任一个标签，不等于检索出所有相关章节。

## 需要保留的两个案例

“MSE 与带 1/2 系数的目标有什么区别？”首先返回 `linear:3`（求导），预期的 `linear:2`（均方误差定义）排第二，分数分别约为 0.2160、0.1424。前三条有依据，但排序仍可改进。

“郑州大学宿舍电费在哪里缴纳？”错误返回 `gradient:2`（学习率与收敛），分数约为 0.1454，超过当前 0.12 阈值。中文单字重叠可能让无关问题得到看似有效的匹配。现有引用检查只保证来源 ID 存在及正文标注一致，不能据此证明引用与问题相关；因此当前检索尚不足以保证可靠拒答。

本轮保留这次基线，未为消除这一个误检而直接调参。后续可在开发集比较词项覆盖约束、中文分词或语义嵌入，再用另行收集、人工标注且未用于调整的测试集验证。若引入新的外部嵌入服务，应先说明成本和数据流并与负责人确认。

## 复现方法

从项目根目录运行，仅需已安装的 Agent 检索依赖：

```powershell
.\.venv\Scripts\python.exe -m eduagent.retrieval.evaluate
```

命令默认使用新词组检查。要重现本文原始基线，加 `--policy baseline`。保存另一次结果时使用新文件名；命令拒绝覆盖已有报告：

```powershell
.\.venv\Scripts\python.exe -m eduagent.retrieval.evaluate --output data/local/retrieval-next.json
```

退出码 0 表示评估完成，不表示所有问题通过。应同时检查 `cases` 中的 `passed`、`first_relevant_rank` 和返回章节。未包含某一类问题时对应比例为 null，不伪造为 0 或 100%。

评估器测试通过人工可核验的固定排名验证指标计算，并检查重复 ID、错误知识点、虚构章节和报告覆盖保护。完整测试命令 `.\.venv\Scripts\python.exe -m pytest backend/tests -c backend/pyproject.toml -q`，实际 **175 passed in 5.49s**。

这些数值不能推广为课程问答准确率、通用检索能力、模型回答正确率或学习效果；资料、问题与标签仍需负责人审阅。

## 助教如何处理依据不足

助教先在本地检索原问题，2000 字问题使用带重叠的 1000 字窗口，避免超出工具长度限制或截掉末尾知识点。若没有合格章节，直接保存 `offline_fallback / insufficient_evidence`，返回真实的规则学习安排，`model_calls=0`、无引用，不改 BKT。

若原问题有候选来源，模型仍通过 LangGraph 调用工具；模型改写检索问题后，仅把同时属于原问题候选来源的片段返回给模型，避免轻易转向其他知识点。最终引用仍须实际检索到并与正文一致。新记录包含 `retrieval_policy=tfidf-phrase-v2`；旧记录没有该字段时返回 null，不补造历史策略。

这些检查只约束词项、章节候选和引用结构。包含课程词的课程外问题仍可能进入模型流程，引用存在也不证明回答每句都受到支持。更强的语义判定、独立人工测试集与真人效果验证仍未完成。
