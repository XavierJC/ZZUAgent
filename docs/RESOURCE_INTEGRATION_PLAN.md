## 按最新反馈补充：真实习题接入个性化闭环（建议，待批准）

用户指出“若资源始终不能加入BKT，是否失去个性化”。该担心对应真实工程缺口：当前正式个性化只覆盖原5点/10演示题，普通个人练习选题按练习次数等原规则，不读正式BKT；只导入为普通练习不能让新题自动成为客观学情证据。上一版四批还缺少正式诊断准入，需要补充，不能把“暂不自动纳入”解释成“永远无法纳入”。

建议新增一个独立的受控准入批次，放在识别样本核验之后、最终课程发布之前：

1. 先把已识别真实题关联原5个正式知识点，模型只建议，负责人核对题型、原文完整性、知识点和标准答案。例：准确率/召回率题关联模型评估；梯度/损失题关联既有对应点。不要把SVM/决策树等硬映射到无关既有点。
2. 仅选择具备可靠客观判分依据、知识点归属明确的题作为“正式诊断候选”。优先单一主要知识点；多知识点题需明确子问和可观测评分，不能同一总分无依据重复更新多个BKT状态。主观文字练习保持独立，模型参考答案不直接成为BKT观测。
3. 增加版本化正式题库准入与显式发布，冻结题目/答案/知识点版本，保留审核和来源。现有Catalog/数据库绑定配置指纹，当前发布只能引用原运行题库；必须先解决新旧配置隔离/兼容及旧历史读取，不能只改JSON或添加一个审核复选框就称完成。
4. 发布后学生的正式作答由原确定性评分服务产生观测，BKT公式更新对应知识点，再据薄弱点/目标/先修选择新的题与关联课件。导入、阅读、模型识别和普通练习本身仍不更新BKT。
5. 验证同一道新题对不同合成学情产生正确状态更新及后续行动；旧作答/旧发布不被新答案改写、重复请求不重复更新、未准入题无法写BKT，题型/知识点冲突拒绝发布。真实教学效果和参数标定仍不由这些测试证明。

此批先扩充原5点的可用诊断题，不要求更换BKT算法或参数，题量以实际可审核资源为准。原40候选依旧待审，不因本补充自动启用。支持向量机、决策树、神经网络的正式BKT接入是下一层范围：需另行确认稳定知识点ID、先修、目标、自评/评分配置与足够题目；不能由标题直接新增掌握概率。即使采用演示参数，也必须标注未统计标定、无作答时待诊断。

本节是根据用户反馈修订的下一步建议，不是正式题库修改/BKT扩点的实施授权。工程现状和原学习事实保持；实施前明确新的准入范围及版本迁移方案。

## 第一批：导入、去重及质量清单

复用现有上传API/文件版本/解析任务及资源角色，建立批次清单：原路径/原名、SHA-256、文档ID/版本/解析ID、页数、资料用途、各页告警及是否重复。资料来自课件目录标为课件，习题目录标为习题资料；不按名称自动确定知识点。

导入前备份现用数据库、记录既有学习事实摘要；桌面原件保持。已存在文件只关联批次，不重复新建或收费。按顺序处理，断点恢复先读取回执，原件或任务损坏明确失败。不因导入自动发布新课程或修改旧发布清单。

验收：8份新PDF登记可恢复、2份重复被复用；原件下载hash一致；逐页位置、失败和待核对项可见；旧笔记/正式评分/BKT/自评事实保持。DOCX转换的布局与公式由负责人确认，未确认时单列待处理，不阻断PDF接入。

## 第二批：小样本模型识别与原文核验

建议先从“模型评估与选择”挑选普通文字、公式、表格/图示各1页，再选择一份习题PDF中不超过3个相邻页面。具体页码在本地解析后明确，不预判封面/目录具有代表性。

模型处理分两类，避免重复转录费用：

- 课件：复用选页视觉识别，原文转录与模型解释分别保存；公式保留可还原的LaTeX，图表说明附位置及待核验标记。
- 习题：复用Agent语义提取，直接提供选定原文和原页图，保存原题型、共有条件、子问、公式/图表依赖及未知答案；程序校验后至多一次结构复核。除非该视觉转录另有复用价值，不先做一遍整页转录再重复提题。

首轮建议**最多5次真实请求**：3次课件单页识别＋习题任务最多2次（含一次复核）。课件沿用每页3000输出token；习题沿用每次10000输出token、任务最多2次。此为待批准上限，不是实际消费记录。需要明确所选文件/页码、本机使用权、发送DeepSeek范围与本轮预算；方案确认不能被当作已同意发送全部502页。网络不确定/超时不自动重发，完成后记录实际次数、用量及失败。

核对矩阵包括：题干/子问有无遗漏、问答题是否被误判为选择题、选项顺序、正负号/上下标/矩阵、图表指代、原文答案是否存在、跨页衔接及引用页码。原文没答案时保持未知，不把模型解题当提取出的标准答案。程序可查结构与来源，语义正确性由负责人对原图确认。

验收：样本中的问题都有明确结果或“无法确定”告警；未解决的题型/公式/关键内容错误不得被标为已核对。样本通过仅证明这些页面，不报告全资料识别准确率。发现关键问题先修复同一链路，再扩批，不无界增加模型调用。

## 第三批：教师课件RAG及受控问答（新增开发范围，待确认）

当前`SourceType`实际只允许course_material/personal_note；教师课件并未进入KnowledgeService检索。需要增量扩展，而非导入后宣称已支持。

1. 新增teaching_material来源，复用TF-IDF方案，教师索引与课程说明/个人笔记独立。按页/标题/段落分块，保留文档ID、文件版本、解析记录、页码、原文片段及内容指纹，不强行映射原5点。
2. 单页模型结果不能替换整份课件的其他页。索引输入使用完整本地解析，加上用户明确采用的对应页转录；保存逐页取用记录及组合内容版本。模型解释不冒充原始课件文字。
3. 原文件/解析取用改变、删除后立即使旧索引失效；发布索引前重查文件/解析/取用版本，失败保留原件，重启可重建。历史引用保存当时片段并标注现时状态。
4. 来源目录、请求模型、引用模型、抽屉与教学发布来源白名单一起扩展；后端强制按标识/课程/文件/版本过滤，空集合不查全库。
5. 教师资料发模型有独立逐轮授权，不能借用个人笔记或课程说明的同意。先在本地准备检索片段并展示教师文件/页码范围，再由显式同意执行模型问答；用户仅勾选来源不等于授权外发。无同意仍可本地查看检索片段。
6. Phase5旧发布清单不改写，新增课件RAG能力通过明确新发布版本启用；检索/讲解不改变BKT和正式评分。无需模型密钥时仍能检索课件。

可能需要增加索引状态/分块及页面取用元数据。实现前重新核对现用schema与任务状态，设计必要的增量迁移并做备份/副本演练/旧表摘要/外键/旧代码兼容与非覆盖式回滚，不提前指定未经实现验证的schema编号。

验收：模型评估课件问题命中所选课件并引用匹配页码；未选文件和其他标识内容不进入结果；无外发同意零教师内容模型传输；更新/删除/重启/并发构建正确；课堂内容与模型补充明确区分。新课件评估单独建样本，保留原55条和5/15误检记录，不用HTTP通过声称语义准确率提高。

## 第四批：扩批、知识导航及课程发布

在小样本验收后，按已确认的文件/页范围分批扩展模型处理；每任务保留现有3页/文本/题数上限、失败状态、调用计数和原件对照，不增加后台无限续跑。

课件按实际讲次建立可编辑知识体系候选，复用4B-2人工确认流程。支持向量机、决策树、神经网络可作为阅读概念，不自动成为正式BKT点。暂不做全量片段语义映射或基于知识图谱重排。

已核对习题进入个人普通练习；单选/判断仍只按人工确认的答案快照评分，主观题保存文字/参考与复习标记，不新增主观自动评分。原10题、40候选状态及正式策略保持。

构建端明确发布带新资料版本的工程演示课程，学生端完成：打开课件→受控问答/页码引用→查看相关习题→普通练习→历史恢复。需要正式诊断时仍走原5点/10题，不把支持向量机等普通练习结果写入BKT。

验收：资料/题目/引用/历史刷新和重启恢复，录入/识别/问答/普通练习前后正式学情摘要不变；真实浏览器桌面/窄屏/键盘检查分开记录，不绕过环境已有浏览器限制。自动测试、真实HTTP、模拟模型、真实模型质量、人工审核及教学效果各自报告。

## 开发边界和交付

本轮只是方案。第一批主要调用现有能力；第二批主要真实质量验证与必要缺陷修复；第三批是主要新增代码；第四批扩批和内容整理。先完成一份课件与一份习题的可用样例，再扩大资料范围。

交付导入/重复/失败清单、样本核对表、真实调用及用量报告、教师RAG来源/引用契约、迁移与回滚记录（如需）、独立检索评估、回归结果和人工待办。原文件不纳入公开仓库，报告仅保留必要索引元数据，不复制整份教师内容或密钥。

原四批没有授权正式题库准入；上方补充建议将其列为需批准的新增批次，优先接入原5点的已审核真实题。新增正式知识点、主观自动评分、新题生成、自动启用40候选、身份/RBAC或全量4B-3语义映射仍不自动实施。批准实施时还需明确导入归属、准入范围及首轮所选页外发范围；范围/费用可一次列清后按界限执行，不逐个普通步骤重复询问。
