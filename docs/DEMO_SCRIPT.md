# 本地演示与工程复验

版本：0.4.1，记录日期：2026-10-20。此脚本证明程序行为，不证明真实学习效果。题目和资料仍待人工审阅，当前启用 10 道题，候选 40 题未启用。

## 演示前

打开 [学习页面](http://127.0.0.1:8000/)，手动刷新以加载最新资源。确认服务运行；启动与构建见 [Web 说明](WEB_GUIDE.md)。使用新的演示标识，以免已有学习目标、累计轮数或已答题影响路径。

以下答题顺序包含标准答案，供负责人验证原型，不是学生成绩或人工题库校验结果。页面会按真实答题证据更新，演示中不手动改数据库。

## 路径一：诊断、练习与推进

1. 新建标识，目标只选择“逻辑回归”。先修顺序为线性回归 → 梯度下降 → 逻辑回归。
2. 查看掌握概览。没有答题证据时应显示待诊断，而不是把 20% 先验描述成真实水平。
3. 先提交 `lr_01` 的 B，再提交 `lr_02` 的 A。查看解析、约 52.6% → 82% 的估计，以及进入梯度下降的依据。
4. 继续 `gd_01` 的 C、`gd_02` 的 D，然后 `log_01` 的 C、`log_02` 的 D。每次提交后先看反馈，再点击继续。
5. 共六次作答后应结束该目标及其先修学习；不代表全部五个知识点已学习，更不代表实际能力已被证明。
6. 打开“学习记录”，核对六条回执。刷新应恢复相同状态，不应自动生成讲解。

如需展示模型讲解，可在某个知识点手动发送具体问题，例如“请解释梯度下降的更新方向”。查看实际章节、模式与依据；该操作可能调用已配置的模型并产生费用，原型不自动发送或重试。

## 路径二：答错、资料不足与题目耗尽

1. 用另一新标识选择“梯度下降”，在首道 `lr_01` 提交 A，形成一次错误观测。
2. 线性回归估计应约为 12.9%，下一步是复习同一先修知识点。正确进入后续知识点仍受阈值约束。
3. 向助教发送“郑州大学宿舍电费在哪里缴纳？”。本版本应返回依据不足的本地反馈、无引用，`model_calls=0`；当前安排仍来自保存的学情，不更新掌握度。
4. 在 `lr_02` 提交 A。由于一次错误后再答对，估计尚未达到阈值，且目前仅启用两道该知识点题目，应明确以 `insufficient_questions` 暂停，不重复旧题或假装完成。
5. 重新打开已有记录，确认两条答题、复习/停止原因和本地反馈能恢复。

这条路径展示当前题量的真实限制。候选题包的“两错三对后推进”只在隔离的自动测试中验证，待人工审阅并正式切换后，才能用于默认学习流程。

## 可复现的 HTTP 工程检查

本轮已实际执行 [verify_workflows.mjs](../scripts/verify_workflows.mjs)，使用前端同一 HTTP 适配器访问本地服务，创建两位合成学习者。已保存 [实际结果](evaluation/workflow-verification-v1.json)：

| 路径 | 实际行为 |
| --- | --- |
| 六次正确作答 | revision=6，三知识点各约 0.82，最终 finish；重复第一事件未二次更新 |
| 首错后本地反馈 | 错后约 0.1290，资料不足反馈不改学情、不调用模型，下一题为复习 |
| 第二题后暂停 | revision=2，停止原因 insufficient_questions，两条历史可读 |
| 新增模型请求 | 0；本轮未重新验证真实模型生成 |

当前 0.4.1 服务运行时，从根目录复现：

```powershell
node scripts/verify_workflows.mjs
```

每次执行会新建合成记录，不删除旧数据。脚本限定目标服务版本，先验证课程外检索为空，再检查该问题的本地反馈；不会发送课程讲解问题。可用额外文件路径保存新报告，文件已存在时拒绝覆盖，不要覆盖本轮证据文件。

## 补充展示：相同学情为什么产生不同安排

使用已保存的 [教学决策对比](POLICY_EVALUATION.md) 展示 8 个配对状态，无需联网或新增学习记录。从根目录复现：

```powershell
.\.venv\Scripts\python.exe -m eduagent.evaluation.compare
```

可说明：“先错后对时，当前演示 BKT 约为 41.3%。固定两题安排会继续下一知识点，当前规则会先保留薄弱先修；由于现用库该知识点只有两题，实际表现为暂停并提示补题。首题答错后的另一处差异只是复习建议，两种策略分配的下一题相同。”

这段展示比较确定性决策，不调用大模型，也不证明复习改善成绩。完整报告同时列出当前策略的三次暂停，不能只展示先修约束计数。候选题仍待人工审阅，不能为使演示更顺利而直接启用。
