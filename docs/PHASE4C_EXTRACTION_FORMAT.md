# 原有习题提取与结构化格式

本阶段提取用户提供的原题，不创造新题。规则版本为 `original-question-rules-v1`。

## 复用与技术

PDF/PPTX/MD/TXT复用 `DocumentsService` 已保存的 `document_units`，按文档/文件版本/解析任务/学生校验后读取。PDF页、PPTX幻灯片和文本位置原样保留。个人笔记直接读原Markdown；课程材料读现有manifest指向的原文。文本型资料无需模型、OCR或模型密钥。

PNG/JPEG/WebP扩展原上传、不可变文件版本、解析队列、受限子进程及原件下载，没有第二套上传库。图片≤20MiB、1600万像素、单帧；本地只登记尺寸/完整图区域并标记需要转录。PDF/图片预览复用同一受限子进程，重新编码为PNG，不执行原文脚本、宏或外链。

可选视觉仍为已有DeepSeek转录适配器：每轮明确选择PDF页或图片编号1并同意外发；最多3页，每页3000输出token；失败、超时或刷新不自动重发。模型仅返回严格的 `transcription_md/interpretation_md/warnings`，重复字段、缺失字段、工具调用等拒绝；只从转录正文提题，不从图示解释提题。**本轮新视觉请求只使用模拟模型，真实兼容性、公式还原及识别准确率未做评估。** 原库已有的2条视觉转录记录/4次历史模型调用计数保持，可直接复用；未有文本的图片需要手工转录或用户另行授权真实调用。

## 分割规则与人工兜底

识别 `1.`、`1、`、`（1）`、`第1题`；跳过代码围栏和独立块公式内的题号。跨页先连续拼接再分割，保留各页交叠片段、精确字符偏移及原文快照，不将换页默认当新题。选项识别A～H，答案仅接受明确的“答案：A”等行或判断题的正确/错误，解析行单独保存。

重复题号、重复选项、答案无法规范化、公式边界、图表依赖等留下提示。未找到编号时保留为待人工修正草稿；图片无文本时创建明确的“待转录”占位草稿，绝不宣称提取成功。无答案不推断，选项外答案不进入评分。

每轮≤30个所选解析单位、12万字符、80题；粘贴≤60000字符。题干/解析各≤16000字符、选项≤12项/每项4000字符，超限拒绝，不静默截断。复杂版面、分栏、非规范题号、行内公式、题后答案汇总以及图示含义均可能需要人工修正；规则不是通用OCR或语义准确性保证。

## 结构格式

```json
{
  "number": "1",
  "question_type": "single_choice",
  "stem": "求 $x^2$ 的导数。",
  "options": [{"key":"A","text":"$2x$"},{"key":"B","text":"$x$"}],
  "answer": "A",
  "explanation": "原文或人工核对后的解析。",
  "concepts": []
}
```

`true_false`使用服务端固定的true/false选项；`other`只允许草稿。概念引用为 `{architecture_id, concept_id}`，必须属于当前演示学生已经发布的体系；可多选，独立于正式BKT知识点。原题稳定ID由服务端生成，不以题号或名称去重。

持久来源含 `resource_id/source_version/content_hash/run_id`、原来源类型/ID、逐页 `unit_id/location/start_offset/end_offset/raw_md/origin/warnings`、原答案文字和候选概念。候选概念只用已发布概念名称的字面匹配，明确标记candidate，不自动成为确认关联。

答案可信度分别为 `source_provided`、`model_inferred`、`human_confirmed`、`unknown`。视觉转录中出现的答案保守归为model_inferred，即使模型声称来自图中，也不能自动成为评分依据。审核记录保存原始答案类别；仅当前版本明确的 `reviewed=true + confirm_answer=true` 才能人工确认。后续修改会重新要求审核。

合并/拆分在同一事务生成新草稿并归档原题，保留原题ID/版本、所有来源及原文片段，清除旧答案确认，不自动推断合并后的答案。不同资料的来源状态分别验证；任何来源变化都会反馈。归档和软删除不物理清除快照、原件或备份。
