# Phase4C-0～2：统一课程资源、原题提取与个人普通练习

2026-10-23导航更新：上传/提取/审核在课程构建“课程资料/习题管理”；学生端“学习资料/普通练习与错题”查看和练习，笔记入口保留。schema11及课程发布/学习来源见[Phase5指南](PHASE5_GUIDE.md)，下文为4C历史。普通练习仍不写BKT。

2026-10-22。授权范围见[本轮任务书](requirements/PHASE4C_TASK_BRIEF.md)。本阶段连续实现资源→提取→人工审核→个人题库→实际普通练习，停止在4C-2；不实现AI新题生成、正式诊断题准入或BKT集成。

## 使用路径

在现有「资料学习工作台」选择「课程资源与习题」。同一工作区有课程资源、提取与审核、普通练习与历史三个步骤。

1. 资源目录自动展示当前学生的已有文件、笔记及课程说明。按用途和标题过滤；选择资料查看原文/解析，点击提取。不需重新上传现有PDF。需要新文件时，展开原有上传/解析管理组件，支持原四格式和PNG/JPEG/WebP；收起时刷新同一目录。
2. 提取默认复用当前本地解析，可指定已完成视觉转录run和页面；也可粘贴已有题目，或手工录题。解析为空/不确定时只生成待转录/待校对草稿。
3. 审核页显示原PDF/图片与原文位置快照，可修改题干、选项、公式、题型、答案、解析，多选已发布知识概念；实时预览使用已有安全Markdown/KaTeX组件。来源候选匹配仅作提示。
4. 保存草稿。人工核对题目后明确勾选审核；只有本人核对答案并单独勾选答案确认，答案才成为普通练习评分依据。单选/判断可确认进入practice，其他题型保留draft。
5. 点击开始本题，或在普通练习按当前课程/概念开始下一题；按最少练习次数确定性选择。提交后显示客观结果/解析或无法判分说明，保留错题、原题版本及来源，可重复练习。刷新恢复只查询原session，不重新分配或评分。

可勾选多道已保存题目合并为新草稿；拆分用独立一行 `---` 分隔题干。合并/拆分会归档原题并生成未审核的新题，答案需重新核对，不自动推断。筛选支持题干、题型、状态、来源、章节及概念；疑似重复仅作提示，不自动合并。归档和来源软删除保留历史，不等于物理清除。

## 复用与模型边界

复用FastAPI学生子资源、SQLite事务/备份/CAS、4B-1的原件/版本/解析单位、受限worker、pdfium预览、DeepSeek转录器、4B-2已发布概念以及Vue输入/Markdown渲染。没有第二套PDF上传或笔记副本库，没有新增依赖或外部服务。

课程和个人笔记仍由原RAG模块管理；统一目录提供稳定引用和RAG能力标识，题目直接复用相同原文。**教师课件本轮仍未接入RAG**，不能把目录登记描述为新增课件检索能力。现有55条检索评估和5/15课程外误检保持，原40候选正式题仍待人工确认，正式演示仍原10题。

本地解析、文本提题、审核和普通练习不需模型密钥。图片本地不OCR，模型转录需独立逐轮选页/图片外发授权；不得沿用Chat授权。本轮新增真实模型调用0；原库本轮开始前已有2条视觉转录记录，累计4次模型调用计数，均与备份完全一致。既有结果可以在下拉框直接选择复用，不需手工复制任务ID。模拟视觉只证明流程、约束和恢复，不证明DeepSeek真实接口兼容性、识别准确率或教学效果。

## 数据模型

现用库迁移前真实schema8/27表，升级目标schema9/34表。新增7表：

| 表 | 保存内容 |
| --- | --- |
| course_resources | 资源稳定身份、原来源引用、用途/章节/概念关联、独立revision；仅粘贴原题保存自有正文 |
| question_extractions | 提取批次、绑定资源版本、规则版本、来源快照和提示 |
| personal_questions | 稳定题目ID、当前结构、来源、draft/practice/archived及revision |
| personal_question_revisions | 追加保存各版本结构与人工审核记录，不覆盖旧版 |
| personal_practice_sessions | 实际展示题目、版本、来源与评分依据快照 |
| personal_practice_attempts | 独立普通练习作答、可空客观结果及时间 |
| personal_bank_operations | 学生/课程/request_id指纹与事务回执 |

目录采用原存储的只读投影，稳定resource_id由学生/课程/原来源类型/ID生成UUID；首次关联或提取时登记元数据，不复制文件或笔记正文。当前文件版本、hash、解析引用、有效状态始终从权威原存储读取，GET不会同步写库。课程原始说明无已知创建时间时返回null，不伪造时间。

关联只接受同学生已发布体系中的章节/概念，明确candidate/confirmed，多对多；不写正式先修图。题目编辑、发布、拆分合并、提交均在单个SQLite事务校验版本并保存回执。相同request_id相同内容重放，不同内容409。旧revision不能覆盖新内容；题号/名称不是身份。

资料更新/删除/重解析时动态报告modified/deleted/reparsed/unavailable；旧题文本与历史练习不变。继续审核或开始旧来源题需明确核对快照。历史作答始终使用开始时的题目和人工确认答案，即使当前题目后来修改或归档。无人工确认答案时correct/score=null，原文答案和模型参考均不能暗中评分。

个人题库服务只借用已有学生存在性校验，没有调用正式next/answers/评分/BKT更新，也没有写students、mastery、decisions、attempts、自评或指南。演示学生标识不是账号认证，本机受控演示范围保持。

## 迁移与回滚

开始前代码归档和27表摘要存于 `data/local/phase4c-prechange-0259bc2a/`。现库备份为 `data/local/eduagent.before-v8-d960b38b4843.sqlite3`。真实迁移和指纹见[迁移报告](../data/evaluation/phase4c-migration-v1.json)。原27表数据摘要、原件/派生物及旧评估均保持，完整性ok、外键0错误；旧8代码接受恢复8副本并明确拒绝9副本，升级后副本另行保留。

除7张新增表，图片支持需要放宽原document_versions.format的CHECK：按SQLite重建表流程，在停写、验证备份后事务内逐列复制、重建约束并比对原27表全部数据。迁移期间临时关闭连接外键执行，提交前做完整foreign_key_check，结束后重新启用；任意DDL或校验失败整体回滚。不是仅修改user_version。普通API拒绝未显式迁移的8库。

回滚不覆盖现用库：停止服务和写入，先备份最新schema9库、整个documents目录、现有代码与前端。另建隔离目录，将before-v8备份恢复为新工作副本，并配套归档的旧schema8代码和前端，再验证后切换；保留升级后的9库和新增数据。旧8代码不能读取9库，新题/作答不会自动合并回8库。副本中验证旧代码接受恢复8库、拒绝9库。不得直接把旧库复制到活动库，也不得只降user_version。

## 前端保护与限制

桌面资源列表/详情、审核原文/编辑器并排；1250px以下审核区纵向，760px以下单栏。表格/代码/公式复用滚动容器，原件预览有宽度限制。所有表单、选项和操作有原生标签/键盘焦点。

题目本机草稿独立于笔记/自评，按学生保存，普通切换保留；刷新读取已保存内容并恢复未保存修改。旧本机revision遇新服务器版本阻止保存，可保留恢复副本、显式读取服务器再手动恢复。写请求发送前保存request_id；断网或服务异常只查回执，不自动重发。切换学生隔离缓存并丢弃旧响应；浏览器关闭提示未保存内容，存储配额错误时阻止写请求。

首版每学生最多1000题（含归档），历史列表最近100次，数据库保留全部session和审核版本。普通练习不是防作弊考试：题库详情和原资料允许本人查看答案。章节/概念过滤只读已发布体系；未确认结构不会被自动采用。
